## Walk A, part 1: NJ formation, signed out (checklist step 7)

Test name "Larkspur Meadow Walkthrough", fictitious agent/member/signer, stopped on
Payment, then cancelled through `/Home/Restart` (Cancel's target). A second pass was the
engine itself: the rebuilt adapter filled all 13 screens and stopped before Pay Now
(32 seconds, fee check ok).

Screen order (live): Welcome, Business Name, Business Designator (name check),
Business Data, Business Purpose, Main Business Address, Registered Agent,
Registered Agent Information, Members / Managers, Other Provisions/Additional
Information, Signatures, Review, Payment.

Corrections to the Nov 14 map:

1. **Welcome screen** with a "Get Started" button comes first. It also advertises a
   *Business Formation Business Account* with a **shared payment account** for firms
   that file often. That is very likely how stored payment works (decision 3); see
   question Q1 below.
2. **Entity type label** is "What type of business would you like to form?"; the LLC
   option is "NJ Domestic Limited Liability Company (LLC)".
3. **Name check wording**: "Congratulations! The Business Name X is available." The
   designator list has 8 options: LLC, L.L.C., LTD LIABILITY CO, LTD LIABILITY CO.,
   LTD LIABILITY COMPANY, LIMITED LIABILITY CO, LIMITED LIABILITY CO., LIMITED
   LIABILITY COMPANY.
4. **Business Data** holds EIN, NAICS, Duration, Effective Date (all optional). The EIN
   is a 9-digit box plus a 3-digit location box defaulting to `000`. Effective Date is
   MM/DD/YYYY, defaulting to today.
5. **Business Purpose is its own screen**, 300 characters, optional PNG/PDF upload.
6. **Main Business Address is optional**: Continue moved on with every field empty. The
   State dropdown uses full names ("New Jersey"); ZIP is split 5 + 4.
7. **Registered Agent** is a choice between a *link* "Enter a Registered Agent/Office"
   and a Registered Agent Number box. Manual entry is a separate screen with Name*,
   **Email (optional, new)**, Office Address 1*/2, City*, State (read-only New Jersey),
   ZIP 5+4, and an **attestation checkbox** ("I attest ... the Registered Agent is aware
   of and has accepted the responsibility..."). The number path was not walked.
8. **Members**: "Add New Member" is a link with role=button. Popup fields as mapped,
   with State as full names and ZIP 5+4; an international-address variant exists.
   Quirk 1 confirmed (Enter from a field posts `Members/ModalAddMember`).
   **Quirk 3 did not reproduce**: Continue with no member moved on to Other Provisions.
   The adapter now checks the member table itself before Continue.
9. **Signatures**: Quirk 2 confirmed and explained (the Save input is `aria-hidden`).
   **Signer Title list for an LLC is only "Authorized Representative"** (open item
   closed). The signature box has no label; it sits under the table's "Signature"
   column. Continue stays disabled until every box is checked.
10. **Review** shows a fifth section, Main Business Address, when one was entered.
11. **Payment** matches the map. Payment Type is a dropdown (Credit Card / E-Check)
    signed out. Notification boxes are pre-checked. Fee table as mapped.
12. **Pay Now is not the last step.** The disclaimer says NICUSA's payment gateway
    processes the payment; card or stored-method entry happens after Pay Now on a page
    nobody has seen yet. The adapter is therefore `complete: false` until walk A maps it.
13. A hidden **Session Timeout Warning** popup on every screen has its own "Continue"
    button; the adapter only clicks visible controls.
14. **Retrieve Documents** needs the confirmation number + email. The engine must store
    the confirmation number the moment the gateway returns it (reconciliation).

## Walk A, part 2: NJ standing certificates, signed out

Public record used: Prudential Financial, Inc. (Entity ID 0100802453). One certificate
was added to the cart to read prices, then removed; cart verified empty.

- Search types as mapped. Choosing a type **posts back** before the name box appears;
  changing the name box posts back again, which swallowed the first Continue click.
- Results grid: per entity, three checkboxes: Short Form, Long Form w/Filing History,
  Long Form w/Officers; columns Business Name, Entity ID, City, Type, Original Filing Date.
- **Prices (cart):** for this corporation, $25.00 statutory per certificate for every
  form; portal admin fee $2.00 per certificate by credit card, $1.00 by eCheck. Shown
  only after a payment type is chosen.
- **Correction, 2026-11-18:** the price depends on the entity type. Verified per record:
  LLC and foreign LLC $50; domestic and foreign corporation, nonprofit and LP $25; the
  admin fee is the same for all ($2 card, $1 eCheck). Choosing E-Check opens a notice:
  the bank account must allow debits from NJ Originator ID 1522077581 ("NJ Govt
  Services"), or the order is expunged.
- Removing a cart item asks "Are you sure you want to delete this record?".
