# Intake coverage

Generated by `npm run coverage` in `web/` from `web/lib/intake/forms.ts`. Do not edit by hand.

Each portal intake form collects the fields its state walkthrough found. The table lists, per filing kind,
the field label the client sees, the engine request path it fills, whether it is required, and the
walkthrough screen it comes from. Paths under `intake.portal.*` and `payroll.stateAnswers.*` are kept on
the filing for the adapters; the engine has no first-class field for them yet.
